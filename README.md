# Tech Store Landing Page

A modern landing page for an electronics store built using HTML and CSS. The project features a clean multi-section layout with a fixed navigation bar, dropdown menu, hover animations, pricing section, featured products, team, branches, and footer.

## Features

- Modern landing page design
- Fixed navigation bar
- Dropdown menu
- Hero section
- Featured products gallery
- Services section
- Pricing table
- Team section
- Branches section
- Top seller section
- Hover effects and CSS animations

## Technologies Used

- HTML
- CSS
- Font Awesome
